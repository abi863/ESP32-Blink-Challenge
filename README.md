# ESP32 Blink Challenge

## Objective
Blink the ESP32 built-in LED at 1-second intervals.

## Description
This project demonstrates ESP32 GPIO control using the built-in LED.

The LED turns ON for 1 second and OFF for 1 second continuously.

## Tools Used
- ESP32
- Arduino C/C++
- Wokwi Simulator

## Simulation
The project was simulated in Wokwi before testing on physical hardware.

## Result
The ESP32 built-in LED blinks at 1-second intervals.
